== found on the board and fixed on the way
1. `install` not in the image (coreutils gone with the package cut): the data
   setup and the SSH host-key script both failed; SSH dead. Boot recorder
   (bootlog-*.txt on p1) showed it: "install: not found".
   -> mkdir/chmod; every command used by the scripts checked against the rootfs.
2. SSH depended on /data. -> host key on /data if usable, else /run (dropbear-hostkey).
3. The health check was WantedBy=multi-user.target and After=device-service,
   which is After=multi-user.target: systemd deleted the job at every boot
   ("Found ordering cycle ... deleted to break ordering cycle"); slots would
   never be committed. -> started by a timer.
4. device-platform-data could be started twice (Wants= from a later unit):
   "Device data already exists" -> idempotent.
